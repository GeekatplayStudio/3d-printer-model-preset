This page is for direct maintenance. It assumes you are comfortable editing source records, but the help chips now explain what each technical field means in print terms rather than raw schema terms.

Printers Store machine identity, technology, and hardware-specific capabilities that later settings rely on.
Materials Store resin or filament properties that influence temperature, exposure, and compatibility decisions.
Profiles Profiles are the actual printer plus material pairings. Most wizard output depends on these rows being accurate.
CSV and JSON Use bulk import for controlled datasets. Use direct JSON editing when you need fast one-off repairs.
